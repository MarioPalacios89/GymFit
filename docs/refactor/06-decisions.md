# Decisiones

- **ADR-001:** Vanilla modular + Vite.
- **ADR-002:** No Astro por ahora; la app es una superficie interactiva autenticada.
- **ADR-003:** Mantener Supabase y sus contratos.
- **ADR-004:** JSDoc antes que migración masiva a TypeScript.
- **ADR-005:** Sin gestor de estado externo.
- **ADR-006:** Storage versionado y aislado por usuario.
- **ADR-007:** `versions/`, `json/` y `codigo.gs` permanecen históricos.
- **ADR-008:** Migración incremental, nunca big-bang rewrite.
