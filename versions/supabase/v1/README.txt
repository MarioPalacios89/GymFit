MarioFit Pro — paquete Supabase

Incluye index.html, estilos.css y app.js.

Funciones conectadas a Supabase: Auth, plan activo, ejercicios y alternativas, Advisor, historial, sesiones, sets, inactividad, fotos privadas y peso corporal.

Abre la app desde un servidor web/hosting (no file://). Inicia sesión con el usuario creado en Supabase Auth.

Seguridad: el frontend contiene solo la publishable key. Nunca agregues service_role al navegador.
